# 🖥️ CipherBreak 

A **JavaFX-based Number Guessing Game** designed with a **neon-style terminal interface**.
The player must guess a hidden number between **1 and 100** while interacting with a **dark cyber-terminal themed UI**.

This project demonstrates **JavaFX GUI development, event handling, and basic game logic** using Java.

---

## 🎮 Game Concept

The system generates a **random number between 1 and 100**.

The player enters guesses through the terminal-style interface.
The system responds with hacker-themed messages indicating whether the guess is **too high, too low, or correct**.

## ▶️ How to Run the Project

### 1️⃣ Install Requirements

* Java JDK (17 or later)
* JavaFX SDK

Download JavaFX from:
https://gluonhq.com/products/javafx/

---

### 2️⃣ Compile the Program

```
javac --module-path "C:\javafx-sdk-21.0.10\lib" --add-modules javafx.controls GuessGame.java
```

---

### 3️⃣ Run the Program

```
java --module-path "C:\javafx-sdk-21.0.10\lib" --add-modules javafx.controls GuessGame
```
